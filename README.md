Необходимо раскомментировать строки и реализовать хук useLocalStorage. 
Хук должен сохранять данные из инпута в localStorage при каждом изменении инпута, и подставлять в инпут значение из localStorage при загрузке страницы.

Хук useLocalStorage должен принимать ключ localStorage и начальное значение.

Должен возвращать текущее значение и функцию для обновления значения.
